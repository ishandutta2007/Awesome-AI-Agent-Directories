# Awesome-AI-Agent-Directories

## Top AI Agent Directories Ecosystem

**Curated List of SaaS Directories & Open-Source GitHub Projects**

*Focused on AI Tool Discovery, Agent Catalogs, Framework Indexes & Implementation Repositories*

**Last updated: October 2026**



This repository tracks notable **SaaS directories** and **open-source projects** for **AI Agent Directories**. These resources help developers and teams discover AI agents, tools, frameworks, and ready-to-run implementations across industries and use cases.



**Examples** include There's An AI For That, Futurepedia, FutureTools, AI Cyclopedia, Toolify.ai, TopAI.tools, Insidr.ai, AI Valley, Dang.ai, and Easy With AI (the category leaders).



**Open-source emphasis**: Community-maintained directories and large collections of working agent implementations are especially valuable. **500-AI-Agents-Projects** and related awesome lists provide extensive, runnable catalogs of agents across industries. This section is heavily expanded.



Contributions welcome! Open a PR to add/update entries. Keep descriptions factual and link to official sites.

## Open-Source GitHub Projects

- **[500-AI-Agents-Projects](https://github.com/ashishpatel26/500-AI-Agents-Projects)**  

  Massive directory of agent implementations across industries — curated collection of practical AI agent use cases with links to open-source projects and, in many cases, runnable code organized by industry and framework.



- **[awesome-ai-agents](https://github.com/slavakurilyak/awesome-ai-agents)**  

  Curated catalog of hundreds of open-source agent projects organized by category (coding agents, research agents, frameworks, etc.).



- **[Awesome LLM Apps / related agent lists](https://github.com/Shubhamsaboo/awesome-llm-apps)**  

  Popular curated collection of LLM applications and agent examples that serves as a practical discovery resource.



- **[AgentIndex-style catalogs](https://agentindex.app/)**  

  Community and open indexes of AI agents, MCP servers, and agent frameworks (often backed by public repositories and contribution models).



- **[buildagentic.ai frameworks directory](https://buildagentic.ai/frameworks)**  

  Tracked directory of open-source agent-engineering frameworks with activity metrics (stars, downloads, release cadence).



- **[LangChain / LangGraph example collections](https://github.com/langchain-ai/langgraph)**  

  Official and community example repositories that function as living directories of agent patterns and workflows.



- **[CrewAI examples and showcases](https://github.com/crewAIInc/crewAI)**  

  Example crews and use-case collections that act as a practical directory of multi-agent implementations.



- **[AutoGPT and related agent ecosystems](https://github.com/Significant-Gravitas/AutoGPT)**  

  Long-running open agent project with extensive community extensions and use-case examples.



- **[Browser-use and computer-use agent lists](https://github.com/browser-use/browser-use)**  

  Open browser-control agent libraries and associated example collections used for discovery of computer-use agents.



- **[Documentation and contribution guides](https://github.com/ashishpatel26/500-AI-Agents-Projects)**  

  Contribution guidelines and indexes that help expand community agent directories with new runnable projects.



### Additional Strong Open-Source Options

- Starting discovery with **500-AI-Agents-Projects** for industry-organized, often runnable agent examples.

- Using **awesome-ai-agents** and similar curated lists for broad coverage of open agent projects.

- Exploring framework-specific example repos (LangGraph, CrewAI, LlamaIndex, etc.) as specialized directories.

- Contributing new agents or fixing links to keep community catalogs current.

- Accepting that commercial directories (There's An AI For That, Futurepedia, FutureTools, Toolify, etc.) still lead in polished search UX, frequent commercial-tool coverage, rankings, and marketing reach.



**Frameworks for building custom systems**: Browse **500-AI-Agents-Projects** or **awesome-ai-agents** → clone relevant implementations → adapt with **LangGraph**, **CrewAI**, or other open frameworks → share improvements back to the directories. Suitable for developers seeking concrete starting points. Many users still rely on commercial AI tool directories for broad commercial-product discovery.
